# Vercel WeChat Webhook

基于Vercel Serverless Function的微信Webhook服务。

## 部署

1. 推送代码到GitHub
2. 在Vercel导入项目
3. 配置环境变量
4. 部署完成

## 环境变量

- WEIXIN_TOKEN
- WEIXIN_ENCODING_AES_KEY
- WEIXIN_APP_ID
- WEIXIN_APP_SECRET
- COZE_API_URL
- COZE_API_KEY
- COZE_BOT_ID

## Webhook URL

部署完成后，Webhook URL为：
`https://your-project.vercel.app/api/webhook`
